# Архив медиа ИФБК «Акулы»

Материалы собраны с публичного старого сайта `ifbc-sharks.ru`.

## Фото

- `media/legacy/` — 1041 оригинальный публичный файл, сохранённый с исходными относительными путями (`upload/…`, `images/…`).
- `photo-download-report.csv` — исходные URL, локальные пути, размеры и SHA-256.

## Видео

Старый сайт не отдаёт прямые видеофайлы: он ссылается на внешний YouTube-канал клуба. Ссылки сохранены в `video-links.txt`. Попытка скачать обнаруженный публичный ролик была остановлена самим YouTube на проверке «Sign in to confirm you’re not a bot»; чужие cookies/обход проверки не использовались. В `media/video/` локального видеофайла нет.

Архив предназначен для тестовой версии сайта и остаётся закрытым от поисковой индексации.
